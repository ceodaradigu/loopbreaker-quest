# Loopbreaker Quest — 2:45 demo script

This script is the final recording plan. The live Nexus segment remains marked
until OAuth is configured and one real additive write has been verified.

## 0:00–0:20 — The loop problem

**Picture:** Hero, then the eight-bar loop graphic.

**Narration:**

> Starting a loop is easy. Deciding what the song needs next is not. Loopbreaker
> reads an Audiotool project and turns the next musical decision into one focused
> mission. It does not grade taste, replace the producer, or change music on its
> own.

## 0:20–0:55 — Evidence from the session

**Picture:** Session scan and its five measured signals.

**Narration:**

> The scan reads the project graph through Nexus: arrangement length, notes,
> pitch palette, patterns, instruments, effects, tempo, and velocity spread. The
> momentum score is a transparent coaching heuristic, not a claim about musical
> quality. This demo session is eight bars long, so arrangement is the clearest
> constraint.

## 0:55–1:25 — One move, not a checklist

**Picture:** Four mission cards; select arrangement, composition, and feel.

**Narration:**

> Four mission families translate those measurements into playable constraints.
> Here, the arrangement mission asks for a B section. The motif mission asks for
> changed contour, register, or rhythm. The feel mission responds to the tight
> velocity range. The artist chooses one move, builds it, then rescans.

## 1:25–1:55 — Hear the move

**Picture:** Variation Forge. Select and play all three strategies.

**Narration:**

> Advice becomes easier to judge when you can hear it. Loopbreaker ships three
> deterministic sixteen-step Tonematrix strategies: call-and-response, register
> lift, and negative space. Browser previews need no account or paid AI API and
> produce the same starting pattern every time.

## 1:55–2:30 — Live Nexus proof

**Picture:** **Replace this placeholder after OAuth.** Connect Audiotool, choose
a test project, run the scan, forge one variation, then show the named
Tonematrix, pattern, and connection in Audiotool beside untouched existing
devices. If the project has no free mixer input, show the new empty mixer
channel that Loopbreaker creates for that connection.

**Narration:**

> In the live path, OAuth requests only project write access. A scan opens the
> selected document and reads its current entities. Nothing changes until I
> press Forge. That one command adds a named Tonematrix and pattern, then connects
> them to a free mixer input. If none exists, it adds one empty mixer channel.
> There is no delete path and existing devices are not mutated.

## 2:30–2:45 — Close

**Picture:** How-it-works section, public repository, and green verification run.

**Narration:**

> Loopbreaker is a composition coach, not an autopilot. The producer keeps
> authorship; Nexus supplies live context and one safe starting move. The source,
> tests, limits, and reproducible build are public.
